# 50 Days to Bloom

A gentle, customizable reset planner and journal for building habits, reflecting regularly, and tracking progress. The default setup is a 49-day plan; you can adjust it to fit your own schedule and goals.


## Features

- **Dashboard:** See your current plan day, completion progress, streaks, and a quick daily habit checklist.
- **Habit and Salah tracking:** Track daily habits across your plan, with dedicated prayer check-ins.
- **Learning and exercise logs:** Record DSA practice, technical and project learning, workouts, recovery, and rest.
- **Daily and weekly journals:** Reflect with prompts for intentions, priorities, gratitude, wins, challenges, and more.
- **Planner:** Customize timetable blocks and planner days, then fill in weekly routines and learning goals.
- **Calendar and progress:** Browse plan dates and review completion summaries and charts.
- **Rules and future-self note:** Keep personal guidelines and write a note for the end of your plan.
- **Customize your plan:** Set a title, start and end dates, duration, habits, completion threshold, journal questions, planner layout, rules, prompts, and light/dark background colors. Changes are drafts until you select **Apply changes**.
- **Settings and backups:** Switch appearance modes, export or import a backup, or reset the app.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

Other useful checks:

```bash
npm run typecheck
npm run lint
```

## Your data

Plan settings and tracker entries are saved in your browser’s local storage; they are not synced to an account or cloud service. Use **Export backup** to save a copy elsewhere. **Reset all** restores the original plan and deletes saved entries and customizations from this browser.

## Built with

React, TypeScript, Vite, Tailwind CSS, Recharts, and Lucide icons.
